# ロゴの出典

各ロゴは各社の商標です。製品を説明する目的で使っています。

| ファイル | 出典 | 備考 |
|---|---|---|
| `gmail.svg` | npm `@iconify-json/skill-icons`（gmail-light） | 公式の4色ロゴ。背景の角丸タイルを除去 |
| `google-workspace.svg` | npm `@iconify-json/logos`（google-workspace） | 公式ロゴ |
| `google-apps-script.svg` | npm `@iconify-json/devicon`（googleappscript） | 公式ロゴ |
| `google-sheets.svg` | npm `@iconify-json/simple-icons`（googlesheets） | 公式ロゴの単色版をブランドカラー（#34A853）で着色 |
| `google-chat.svg` | npm `@iconify-json/simple-icons`（googlechat） | 公式ロゴの単色版をブランドカラー（#00AC47）で着色 |
| `claude.svg` | npm `@iconify-json/logos`（claude-icon） | 公式ロゴ |
| `anthropic.svg` | npm `@iconify-json/logos`（anthropic） | 公式ロゴ |
| `quire.svg` | GitHub `quire-api/quire-api`（doc_template/quire_logo.svg） | Quire 公式 API ドキュメントのロゴ |

Google スプレッドシートと Google Chat は、作成環境から Google の配布元に接続できなかったため単色版を使っています。
最終的な資料では、Google の公式配布元（Google Workspace のブランド資料）から取得したカラー版への差し替えをおすすめします。
