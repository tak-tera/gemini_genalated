# メールから“自分のタスク”をワンタップで Quire へ

## 課題

- メールや会議で発生した作業を、手で Quire に転記している
- 転記漏れや、どのプロジェクトに入れるかの迷いが起きる

## 仕組み

- AI（Claude）がメールなどを読み、タスク候補と登録先を提案する
- 本人が Google Chat のカードで確認し、ワンタップで Quire に登録する

## 特徴

- **予定と作業を分ける**：会議・講演の日時はカレンダー、準備や事後の作業は Quire
- **登録先は台帳で判断**：振り分けルール（スプレッドシート）をもとに推定し、直した結果から学習する
- **Google Cloud 不要**：Gmail・スプレッドシート・Google Chat・Apps Script・Quire API で構成
- **安全に配慮**：秘密情報はコードに置かない／署名付きリンク／本人のみアクセス可／AI は登録しない（下書きまで）
- **メール以外にも使える**：議事録・チャット・手入力からも、共通スキルで同じ流れに乗せられる

## 使っているもの

| 役割 | サービス |
|---|---|
| 入口 | Gmail（毎時チェック）、議事録・チャット・手入力（共通スキル） |
| 判断 | Claude（定期実行タスク） |
| 台帳 | Google スプレッドシート（振り分けルール／設定／登録ログ） |
| 確認 | Google Chat（Webhook）＋ Apps Script（確認ページ） |
| 出力 | Quire（Quire API） |

## ひとこと

AI は下書きまで。決めるのは人。判断の記録が台帳に残り、使うほど振り分けが賢くなる。
