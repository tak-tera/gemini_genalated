# 設定手順

所要時間は 15 分ほどです。最初は「お試し」モード（カレンダーに書き込まない）で始めます。

## 0. 用意するもの

- メインのアカウント（terao.takeshi@t-consulting.biz）
- メインのカレンダーリストに TU カレンダー（takeshi.terao.c4@tohoku.ac.jp）が追加され、**変更権限**があること（確認済み）
- 新しいスプレッドシート（名前の例:「カレンダー半同期 設定」）

## 1. Apps Script プロジェクトを作る

1. メインのアカウントで https://script.google.com/ →「新しいプロジェクト」。名前の例: `カレンダー半同期`
2. 左の歯車「プロジェクトの設定」で「`appsscript.json` マニフェスト ファイルをエディタで表示する」にチェック。
3. コードは clasp で送ります（[../../docs/clasp.md](../../docs/clasp.md)）。
   スクリプト ID を `calendar-sync/.clasp.json` に入れて main にマージするか、手元で `npm run calendar:push`。
   `appsscript.json` で Calendar API の高度なサービスも有効になります。

## 2. スプレッドシートをつなぐ

1. スプレッドシートの URL `https://docs.google.com/spreadsheets/d/【ここ】/edit` の部分を控えます。
2. 「プロジェクトの設定」→「スクリプト プロパティ」に `SPREADSHEET_ID` = 控えた ID を追加。
3. エディタで `setupSheets` を実行（初回は権限の承認画面が出ます）。
   「設定」「組織」「分類ルール」「タイトル整形」「同期ログ」のタブが初期値つきでできます。

## 3. 確認する

1. `checkSetup` を実行し、ログがすべて `OK` であることを確認。
2. `testOutOfOffice` を実行。
   - `OK` … TU に「不在」形式でブロックを作れます。
   - `NG: 不在予定を作れませんでした` … 「組織」タブの「ブロック形式」を `予定あり` に変えます。

## 4. お試し（書き込みなし）

1. `previewSync` を実行。
2. 「プレビュー」タブに、予定ごとの判定（打ち合わせ／研修講演／対象外…）と、
   本番にした場合の操作（作成・紐付け・更新・削除）が出ます。
3. 判定がおかしいものは、シートを直して `previewSync` をもう一度実行します。
   - 分類の言葉が足りない → 「分類ルール」のキーワード欄に `;` 区切りで追加
   - 余白を変えたい → 「分類ルール」の前後の余白（分）
   - TU のタイトルの整え方 → 「タイトル整形」に行を追加
   - 写したくない TU 予定 → 「タイトル整形」で行き先を `写さない` にした行を追加

## 5. 本番にする

1. 「設定」タブの「書き込みモード」を `本番` に変更。
2. `installTriggers` を実行（10分ごとに `syncAll` が動きます）。
3. 最初の数日は「同期ログ」と TU カレンダーを目で確認します。
   手作業での TU ブロック入力はやめてかまいません（手作業のブロックは消さずにそのまま残ります）。

止めたいときは「書き込みモード」を `お試し` に戻すだけです（トリガーは動きますが何も書き換えません）。

## 組織を増やすとき

1. その組織のカレンダーをメインのカレンダーリストに追加し、変更権限をもらう。
2. 「組織」タブに1行追加（組織コード・カレンダー ID・接頭辞・色番号・ブロック時間・曜日）。
3. 必要なら「タイトル整形」にその組織用の行を追加。
4. `previewSync` で確認してから本番へ。
