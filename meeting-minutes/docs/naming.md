# リソースの名前（接頭語 `mtgmin`）

この仕組みで作るものには、すべて接頭語 **`mtgmin`**（**m**ee**t**in**g** **min**utes ＝ 議事録）を付けます。

- Google Cloud のプロジェクト ID でも使えるよう、半角英小文字だけにしています。
- 区切りは `-`（ハイフン）にそろえます。Drive の検索で `mtgmin` と入れたときに見つかりやすくするためです（`_` だと一語とみなされて見つからないことがあります）。
- Drive で `mtgmin` を検索すれば、この仕組みのものが一覧できます。

## 一覧

| 種類 | 名前 | 作る手順 |
|---|---|---|
| Google Cloud プロジェクト（AI Studio） | 名前 `mtgmin-gemini` / ID `mtgmin-gemini-tc` | setup 1 |
| Gemini API キー | `mtgmin-gas-key` | setup 1 |
| 予算アラート | `mtgmin-budget` | setup 1（任意） |
| スプレッドシート | `mtgmin-管理シート` | setup 0 |
| Apps Script プロジェクト | `mtgmin-gas` | setup 2 |
| 作業フォルダ（文字起こしの置き場） | `mtgmin-文字起こし（作業用）` | setup 4（自動作成） |
| 文字起こし文書 | `mtgmin-文字起こし-【元ファイル名】（1/4）` | 自動作成・保持日数後に自動削除 |
| 議事録フォーマット文書 | `mtgmin-議事録フォーマット` | setup 5 |
| 監視フォルダ | `mtgmin-in-【会議名】`（例: `mtgmin-in-A社定例`） | 任意 |
| 監視フォルダをまとめる親フォルダ | `mtgmin-録音` | 任意 |
| Claude の定期実行タスク | `mtgmin-整理と追記` | setup 7 |
| Gemini 側の表示名（ファイル・バッチ） | `mtgmin 【元ファイル名】` / `mtgmin 文字起こし 【元ファイル名】` | 自動 |

## 付けなくてよいもの

- **追記先の Google ドキュメント**: 普段使っている議事録の文書をそのまま使えます。名前を変える必要はありません。
- **スプレッドシートのタブ名**（監視フォルダ・設定・処理ログ・整理結果）と**スクリプト プロパティ名**（`SPREADSHEET_ID`・`GEMINI_API_KEY`）: コードがこの名前で読むので変えないでください。
- **元の録音・録画ファイル**: 名前に日時を入れておくと開催日時の判定が確実になります（例: `20261021_1400.m4a`）。

## 接頭語を変えたいとき

`apps-script/Config.gs` の `PREFIX` を変えると、これから自動で作られるフォルダ・文書・Gemini 側の表示名が変わります。
手で作ったもの（スプレッドシートやプロジェクトなど）は、それぞれの画面で名前を変えてください。
