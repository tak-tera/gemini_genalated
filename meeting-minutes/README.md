# 会議の録音・録画 → 議事録（Google ドキュメントへ追記）

Google ドライブの決めたフォルダに録音・録画ファイルを置くと、文字起こし → 議事録フォーマットで整理 →
フォルダごとに決めた Google ドキュメントの末尾へ追記、までを自動で行う仕組みです。
2時間を超える録音や、200MB を超える録画にも対応します。急ぎではない前提で、10分ごとに少しずつ進めます。

## 全体の流れ

```
Google ドライブの監視フォルダ（フォルダごとに追記先ドキュメントを決める）
   │ 録音・録画ファイルを置く
   ▼ 10分ごと
Apps Script ── 16MB ずつ分割して ──▶ Gemini API（Files API。1ファイル2GBまで）
   │                                   │ 30分ずつ区切って文字起こし（話者・時刻・話し方・画面の内容つき）
   │                                   │ バッチ方式なら料金は約半額、結果は数分〜数時間
   ▼                                   ▼
作業フォルダに区間ごとの文字起こし（Google ドキュメント）を保存 → 処理ログ「整理待ち」
   │
   ▼ 1〜2時間ごと
Claude の定期実行タスク
   │ 文字起こし＋会議メモ＋カレンダーを照合し、議事録フォーマットで整理
   ▼
スプレッドシート「整理結果」タブに1行ずつ書く → 処理ログ「追記待ち」
   │
   ▼ 10分ごと
Apps Script ── 見出し・箇条書き・チェックボックス・太字に整えて ──▶ 追記先ドキュメントの末尾
   │
   ▼ 保持日数（既定7日）が過ぎたら
文字起こしをゴミ箱へ（残るのは整理済みの議事録だけ）
```

| 役割 | 担当 |
|---|---|
| 新しいファイルの検出、Gemini への分割アップロード | Apps Script |
| 文字起こし（音声を聞く、録画の画面を読む） | Gemini API |
| 会議メモ・カレンダーとの照合、議事録への整理 | Claude（定期実行タスク） |
| Google ドキュメントへの書式付き追記、文字起こしの削除 | Apps Script |

Claude は音声を直接聞けないため、文字起こしは Gemini が担当します。
その代わり、後で空気感・キラーフレーズ・合意の確度まで整理できるよう、要約せずに話し方や間、画面共有の内容まで書き起こさせています。

## 大きなファイルへの対応

- Apps Script は一度に約50MBまでしか扱えないため、Drive のファイルを 16MB ずつ読み出して Gemini に送ります。
  1回の実行（最大6分）で終わらなければ、次の実行で続きから送ります。
- 長い録音は30分ずつ（前後30秒重ねて）区切って文字起こしします。1回の出力上限で文字起こしが途切れるのを防ぐためです。
- 動画は既定で低画質モードにして、2時間でも Gemini が一度に扱える量に収めます。
  画面共有の資料を細かく読ませたいときは、設定タブの「動画の画質」を「標準」にします（1時間程度まで）。
- 2GB を超えるファイルは「対象外」になります。音声だけを取り出すか、分割して置き直してください。

## データの範囲

データが通るのは Google Workspace（ドライブ・ドキュメント・スプレッドシート）、Gemini API（有料枠）、Claude だけです。
Gemini API の有料枠では、送った内容が Google の製品改善に使われません（無料枠では使われることがあるため、必ず有料枠にします）。
Gemini 側に送ったファイルは文字起こしが終わると削除し、残っていても48時間で自動的に消えます。

## スプレッドシート

「mtgmin-管理シート」というスプレッドシートを使います。タブは4つで、`setupSheets` を実行すると作られます。

- **監視フォルダ**: 有効 / フォルダ名 / 監視フォルダ / 追記先ドキュメント / メモ文書（任意）
- **設定**: 音声・動画それぞれのモデルと予備のモデル（理由は `docs/models.md`）、処理方式（バッチ／通常）、区切りの長さ、動画の画質、保持日数、議事録フォーマット文書 など
- **処理ログ**: 1ファイル1行。ステータスは 待機 → アップロード中 → Gemini準備中 → 文字起こし中 → 整理待ち → 追記待ち → 追記済
- **整理結果**: Claude が書いた議事録（1行1段落）。追記が終わると消えます

## 会議メモの扱い

監視フォルダごとに「メモ文書」を指定できます。空欄なら追記先ドキュメントそのものをメモとして読みます。
メモに複数日分が蓄積されていても、録音日時に合うセクションだけを使い、そこを重点的に深掘りします。

## 名前の付け方

API キー、Apps Script、フォルダ、スプレッドシートなどには、共通の接頭語 `mtgmin`（meeting minutes）を付けます。
一覧は `docs/naming.md` を参照してください。

## フォルダ構成

- `apps-script/` … Apps Script のコード
- `docs/setup.md` … 設定手順
- `docs/claude-routine.md` … Claude の定期実行タスクに渡す指示文
- `docs/models.md` … モデルの選び方（Argon を使う理由、Transcribe を使わない理由）
- `docs/naming.md` … リソースの名前の一覧（接頭語 `mtgmin`）
- `docs/format.md` … 議事録フォーマット（Google ドキュメントに貼って使う原稿）
